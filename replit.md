# RD Trauma Healing

Trauma-informed therapeutic practice website with interactive booking, appointment calendar, and Google Sheets integration.

## Run & Operate

- `npm run dev` — run the local Vite development server
- `npm run typecheck` — TypeScript typecheck
- `npm run build` — production build for Vercel deployment
- `npm start` — preview local production server

## Stack

- React 19, Vite, Tailwind CSS v4, Framer Motion, Wouter
- Interactive appointment calendar with working-day slot selection
- Unified Google Sheets API integration & Vercel serverless function (`/api/appointments`)
- npm package management
